## State definitions

- `implemented`: the port status records the behavior as implemented; source review can still be open.
- `partial`: some behavior is present, with known gaps recorded in the next step.
- `open`: Rust work or source comparison remains.
- `out_of_scope`: the behavior is excluded from the running HBC application parity target.
- `source_reviewed`: a recorded source comparison is complete for this area.
- `dolphin_tested`: the named case passed in Dolphin; real Wii behavior remains unverified.
- `hardware_pending`: real Wii behavior has not been verified.

Unprefixed C references use `C-sources/hbc-reborn/channel/channelapp`. References prefixed with `reborn:` use `C-sources/hbc-reborn/channel/channelapp`; `reborn-sdk:` references use `C-sources/hbc-reborn/sdk`; `libogc:` references use `C-sources/libogc`. Rust references prefixed with `sdk:` use `Devtools/libogc-rs`. Update the CSV ledger, then run `python3 tools/parity.py refresh` and `python3 tools/parity.py check`.
